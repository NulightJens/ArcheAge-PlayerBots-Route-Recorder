Before you start

A working AAEmu setup comes first.

You need a working local AAEmu Game server and an online GM character with command access level 100. The full PlayerBots mod is not required. AAEmu 1.2 r208022 is the tested baseline. Other revisions, including r208088, are experimental and can be tried when Check connection returns a valid position. If problems persist, use a matching r208022 server/client setup.

The download includes the recorder, its small server extension and this guide. It does not include AAEmu, game files or a database.

Need to set up AAEmu?

Start with the official AAEmu GitHub repository and setup wiki. Ask in the AAEmu Discord for help choosing a compatible 1.2 setup. The latest development branch and its instructions can target a different version.

Which AAEmu revision was checked?

The recorder bridge was validated against AAEmu source 62e3eb1 for 1.2 r208022. Other revisions need their own compatibility check. The installer checks the server folder layout; it does not certify the server revision.

One-time setup

Connect the recorder to your server.

  1. Extract the entire ZIP

    Right-click the downloaded ZIP → Extract All. Keep all its files together in a normal folder, such as Documents. Open PlayerRouteRecorder.exe from that folder.

  2. Choose your Game server

    Close the Game server using its normal graceful shutdown. In the recorder, open Server setup → Choose Game EXE… and select the AAEmu.Game.exe you normally run.

    AAEmu.Game.exe is the server. AAEmu.Launcher.exe opens the game client. If you built AAEmu yourself, look under AAEmu.Game\bin\Debug\net10.0\ or Release\net10.0\; some builds also have an x64 folder. Select the actual output you use to start Game.

  3. Install the extension, then start Game

    Click Install extension. It adds one position-reading script to Scripts\Commands. Start Game normally again, then log into your GM character. AAEmu loads the extension during startup; an already built server needs no rebuild or database migration.

Already used the standalone recorder?

Extract the new download and click Check connection. If it works, you are ready. Reinstall the extension only if it is missing or you now run Game from a different output folder. Your quick mark buttons stay saved on this Windows account.

Everyday use

Connect. Name the walk. Record.

  1. Check connection

    Log into the game, open the recorder, enter your exact GM character name and your Client build (for example ArcheAge 1.2 r208088), then click Check connection. The build is your declaration, not an automatic detection.

  2. Enter From / to

    Use landmarks, for example Village gate → East bridge. The walk name fills itself in. Enable Take game photos while recording if you want photos too.

  3. Start recording and walk

    Return to the game and travel normally. Finish with Stop & export, then click Show export. Try a two-minute walk before a long trip.

Route settings keeps road type, direction and frequency. The default is one point every 2 seconds. Press Ctrl + Alt + R to pause or resume. Keep separate routes for walking, swimming and transport; only mark a road bidirectional after checking both directions.

Mark what you find

A useful note in one click.

While recording, scroll below the note field to 4. Quick mark options. Click Quest, Fork, Merchant or Mail to save that label at your current location.

To make your own button, enter a word or short phrase in New button and click Add quick mark, or press Enter. Use the small x beside a button to remove it. You can keep 24 labels of up to 40 characters each; your choices survive closing the tool and extracting a newer version.

Quick marks preserve any longer note you are typing in section 3. Marking is disabled while paused. If the connection fails, the recorder tells you to retry; it does not save a made-up location.

Explore a town

Connect streets at named junctions.

  1. Choose City / area network

    Enter the area name in Area name. From / to is unnecessary. Start recording.

  2. Mark each junction

    In City junctions, name the place and click Mark junction. Walk to the next place and mark it too.

  3. Return and explore another branch

    At the same junction, choose its existing name and mark it again. Use a different name for a different floor. The tool joins explicit matching junctions within 1.5 metres horizontally and 0.75 metres vertically; it never guesses connections from map crossings.

  4. Stop & export

    The ZIP includes route.json, network.json and navigation-prior files for the extractor. Loops stay intact. Only walked directions become edges. Pause before any unrecorded move.

Example: Gate → Market → Merchant → Market → Mail → Market → Gate. Keep Quest, Merchant, Mail and obstacle notes in Quick marks. See the network data guide for fieldwork and export details. These exports are collection evidence; they do not install themselves into bots.

Optional photos

Collect a view along the route.

Tick Take game photos while recording. Photos use their own interval, every 5 seconds by default. A single open ArcheAge window is selected automatically; choose your window in Photo settings if several are open.

F9 does nothing in your client?

Open Photo settings → Photo source → Visible window capture. Use windowed or borderless mode and keep the game fully visible on one monitor. This option takes a picture of the visible game area without relying on the game screenshot key or its save folder. Keep other windows out of the game area.

Use the game’s own screenshots instead

The default photo source presses F9 and collects new files from Documents\ArcheAge\ScreenShots. First take a screenshot manually and confirm a new file appears. If your key or folder differs, change it in Photo settings. Original files stay in the game folder. If the client cannot save a screenshot manually, choose visible window capture.

Keep the game in front while recording; switching away or pausing skips photos. At a landmark, stand still, turn the camera and press Ctrl + Alt + P for an extra view. These are separate photos along your walk, not a stitched 360° panorama. Photo positions are approximate.

Use View photos to review the result. Photo settings also controls image width and storage limits. Keep space for screenshots, collected copies and exports.

Contribute on your own time

Make the next route easier to follow.

Short town exits, forks, bridges and road connections are good first trips. Mark quest interactions, merchants, mailboxes, obstacles and places where a crossing fails. Include the zone, nearby landmarks and what you observed. Failed attempts and normal detours are useful too.

Click Show export. Keep the route ZIP and, if you took photos, the separate -street-view.zip, along with their .sha256 files. Exports go to Documents\ArcheAge Routes\exports by default. To browse photos offline, extract the entire Street View ZIP and open its index.html.

Review pictures and notes for names, chat or anything private before sharing. Contact Over1ander in the AAEmu Discord to arrange sending your recordings. The recorder does not upload automatically, and this website does not accept direct uploads.

If something gets stuck

A few quick checks.

I cannot find AAEmu.Game.exe

It belongs to the built AAEmu server, not the client launcher. If you only have AAEmu.Launcher.exe, follow the AAEmu setup wiki or ask the AAEmu community for help setting up a compatible 1.2 server. The recorder requires that local server to read positions.

Check connection fails or no sample appears

Read the specific message beside your character. No commands loaded means a Game script compilation problem; insufficient privileges means GM access; character not found means the name is wrong or offline. If AAEmu answers but the command returns nothing, try the command below and check the Game log. A newer client build alone does not identify the cause. You can correct the loopback API address in Server setup.

Confirm Game restarted after installation and the named GM character is online. In game, /playerrouteposition sample should return PLAYER_ROUTE_SAMPLE_V1. Unknown command means the extension did not load; insufficient privileges means the character lacks the required command access.

The Game server’s active Config.json should have WebApiNetwork host 127.0.0.1 and port 1280. Keep this administrator API on loopback. The installer does not edit settings; restart Game normally after a configuration change.

The installer reports a conflicting extension

Keep the existing file intact and ask the server owner to compare versions. Do not install a second copy of the same command under a different name. A matching standalone copy is reused automatically.

The recorder will not open, or the route will not export

Run the EXE from the fully extracted folder. Startup diagnostics are under %LOCALAPPDATA%\ArcheAge Route Recorder\logs. For an empty export, walk farther and check the sample count and bottom log. Stationary-only recordings may have no traversable segment; raw files remain under working-recordings.
